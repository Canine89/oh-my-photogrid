## 2. 몰입을 만드는 설계 원칙 → 적용
| 원칙 | 적용 |
|---|---|
| 몰입(Flow): 목표가 분명하고 즉시 반응하며 방해가 없음 | 어두운 캔버스, 사진을 만지는 동안 도구 막대가 흐려짐, 편집 중에는 대화상자 없음 |
| 첫 즐거움까지의 시간 | 사진을 고르면 바로 완성된 콜라주가 나타나고, 칸이 스프링으로 "톡" 튀어나오며 채워짐 |
| 가변 보상 (Hook 모델) | **섞기(Shuffle)** 버튼: 같은 사진으로 새로운 배치·스타일·배경색을 무작위로 |
| 직접 조작 | 배치 썸네일에 **내 사진이 들어간 미리보기**를 보여 줌, 칸이 새 위치로 미끄러지듯 이동 |
| 마이크로 인터랙션·햅틱 | 배치 선택·섞기 때 가벼운 틱, 자리 바꾸기·저장 완료 때 확실한 클릭 |
| 피크엔드 법칙 | 저장을 클라이맥스로: "현상 중" 도형 모핑 → 흑백에서 컬러로 **인화되듯 나타나는 결과** → 크게 공유 |
| IKEA 효과 | 섞기 뒤에도 손으로 다듬게 유도(선택된 칸 바로 조작) |
| 스큐어모피즘 | 다크룸·인화지 은유(현상 중, 인화 애니메이션), 기기 테두리 미리보기 |

피해야 할 것: 가짜 로딩 지연, 연속 사용 압박, 과도한 햅틱.
접근성: 텍스트 대비 4.5:1 이상, 터치 영역 48dp 이상, 시스템의 "애니메이션 삭제"를 켜면 모든 장식 모션을 끔.

## 4. 화면별 변경
- **홈**: 폴드 8이 접혔다 펴지며(커버 10:16 ↔ 메인 4:3) 안의 사진들이 다시 배치되는 히어로 애니메이션. 사진처럼 보이는 그라데이션을 써서 "그리드 고르기"로 오해하지 않게 함. 큰 헤드라인, 누르면 살짝 눌리는 목적 카드
- **에디터**
  - 투명한 상단 바와 라임 알약형 "저장" 버튼
  - 사진 평균색 앰비언트 글로우와 기기 테두리 안의 캔버스
  - 접었을 때: 화면 아래에 떠 있는 알약형 도구 막대(배치·사진·꾸미기·크기 + 섞기), 도구는 떠 있는 둥근 시트로 열림
  - 펼쳤을 때: 여백을 둔 떠 있는 둥근 사이드 패널
  - 배치 썸네일에 내 사진을 그려서 보여 줌
- **저장**: 도형 모핑 "현상 중…" 화면 → 인화되듯 나타나는 완성본(스프링 확대 + 햅틱) → 공유 / 배경화면 / 계속 편집
- **아이콘**: 검정 바탕에 라임 와이어프레임

  - `PurposeCards.kt`: 목적 카드
- 에디터

  - 사진 평균색 글로우 `AmbientGlow`
  - 내 사진으로 그린 배치 썸네일 `LiveTemplateThumbnail`

  - 인화 연출 `ExportDialogs.Reveal`
- 햅틱: 배치·스타일·크기를 고를 때 `SegmentTick`, 섞기·자리 바꾸기·저장 완료 때 `Confirm`

  - 안내 화면의 딤 배경은 시맨틱을 병합하지 않는다(TalkBack이 카드 내용을 읽을 수 있음)

## 6. 두 번째 테마 — "가족 앨범" (v1.3)

작성일: 2026-09-24. 홈 화면 오른쪽 위의 알약형 스위치로 **다크룸 ↔ 가족 앨범**을 고른다. 고른 값은 기기에 저장된다(`settings` SharedPreferences, 기본값은 다크룸).

### 방향
가족 사진 앱(패밀리 앨범, 구글 포토 추억, 디지털 액자)이 공통으로 추구하는 **따뜻함·편안함·종이 앨범의 촉감**을 가져온다. 기술적인 느낌의 다크룸과 달리 "앨범 한 장을 넘기는" 느낌을 목표로 한다.

| 항목 | 다크룸 | 가족 앨범 |
|---|---|---|
| 배경 | Ink `#0B0B0E` | 크림 `#FAF5EE` |
| 카드·시트 | Graphite `#131317` | 따뜻한 흰색 `#FFFEFB` + 모래색 테두리 |
| 칩·빈 타일 | Slate `#1B1B21` | 린넨 `#F4ECE1` |
| 글자 | Paper `#F4F4F6` / Mist `#A3A3AE` | 코코아 `#3B2F2A` / 나무껍질 `#6E5F55` |
| 강조색 | Wire Lime `#D4FF4F` | **테라코타 `#B94E34`** (흰 글자 5.0:1, 크림 위 4.6:1) |
| 보조색 | Violet · Coral | 세이지 `#56724B` · 버터 `#EDB94C` |
| 서체 | Pretendard 800, 자간 −2~−3% | Pretendard 700, 자간을 절반으로 줄여 더 부드럽게 |
| 문구 | "어디에 쓸 콜라주인가요?" / "현상하는 중…" | "우리 가족 사진, 어디에 담아 볼까요?" / "앨범에 담는 중…" |

- 휴대폰 그림(폴드 히어로, 기기 테두리 미리보기)은 두 테마 모두 어두운 기기로 그린다. 실제 기기처럼 보이게 하려는 것이다
- 인화지(배치 썸네일 바탕, 저장 완료 화면의 인스턴트 필름 테두리)는 두 테마 모두 흰색이다
- 라이트 테마에서는 상태 표시줄·내비게이션 바 아이콘을 어둡게 바꾼다. 전체 화면 대화상자(현상 중·완성)에도 같이 적용한다

### 구현
- `ui/theme/Theme.kt`
  - `AppTheme` enum이 테마 목록이고, `WfPalette`가 역할별 색 묶음이다
  - `Wf.*` 색 토큰은 이제 역할 이름을 쓴다: `Bg`, `Card`, `Well`, `Raised`, `Line`, `Text`, `TextDim`, `Accent`, `OnAccent`, `Accent2`, `Accent3`, `Print`, `PrintHole`, `Device*`
  - 이 토큰들은 `LocalWfPalette`에서 읽는 `@Composable` 값이다. 그래서 `Canvas`의 draw 람다 안에서는 쓸 수 없고, 람다 밖에서 지역 변수로 받아서 넘긴다
- 테마를 추가하려면 `AppTheme`에 항목 하나와 `WfPalette` 하나를 추가하면 된다
