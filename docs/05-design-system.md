## 2. 몰입을 만드는 설계 원칙 → 적용
| 원칙 | 적용 |
|---|---|
| 몰입(Flow): 목표가 분명하고 즉시 반응하며 방해가 없음 | 어두운 캔버스, 사진을 만지는 동안 도구 막대가 흐려짐, 편집 중에는 대화상자 없음 |
| 첫 즐거움까지의 시간 | 사진을 고르면 바로 완성된 콜라주가 나타나고, 칸이 스프링으로 "톡" 튀어나오며 채워짐 |
| 가변 보상 (Hook 모델) | **섞기(Shuffle)** 버튼: 같은 사진으로 새로운 배치·스타일·배경색을 무작위로 |
| 직접 조작 | 배치 썸네일에 **내 사진이 들어간 미리보기**를 보여 줌, 칸이 새 위치로 미끄러지듯 이동 |
| 마이크로 인터랙션·햅틱 | 배치 선택·섞기 때 가벼운 틱, 자리 바꾸기·저장 완료 때 확실한 클릭 |
| 피크엔드 법칙 | 저장을 클라이맥스로: "현상 중" 도형 모핑 → 흑백에서 컬러로 **인화되듯 나타나는 결과** → 크게 공유 |
| IKEA 효과 | 섞기 뒤에도 손으로 다듬게 유도(선택된 칸 바로 조작) |
| 스큐어모피즘 | 다크룸·인화지 은유(현상 중, 인화 애니메이션), 기기 테두리 미리보기 |

피해야 할 것: 가짜 로딩 지연, 연속 사용 압박, 과도한 햅틱.
접근성: 텍스트 대비 4.5:1 이상, 터치 영역 48dp 이상, 시스템의 "애니메이션 삭제"를 켜면 모든 장식 모션을 끔.

## 4. 화면별 변경
- **홈**: 폴드 8이 접혔다 펴지며(커버 10:16 ↔ 메인 4:3) 안의 사진들이 다시 배치되는 히어로 애니메이션. 사진처럼 보이는 그라데이션을 써서 "그리드 고르기"로 오해하지 않게 함. 큰 헤드라인, 누르면 살짝 눌리는 목적 카드
- **에디터**
  - 투명한 상단 바와 라임 알약형 "저장" 버튼
  - 사진 평균색 앰비언트 글로우와 기기 테두리 안의 캔버스
  - 접었을 때: 화면 아래에 떠 있는 알약형 도구 막대(배치·사진·꾸미기·크기 + 섞기), 도구는 떠 있는 둥근 시트로 열림
  - 펼쳤을 때: 여백을 둔 떠 있는 둥근 사이드 패널
  - 배치 썸네일에 내 사진을 그려서 보여 줌
- **저장**: 도형 모핑 "현상 중…" 화면 → 인화되듯 나타나는 완성본(스프링 확대 + 햅틱) → 공유 / 배경화면 / 계속 편집
- **아이콘**: 검정 바탕에 라임 와이어프레임

  - `PurposeCards.kt`: 목적 카드
- 에디터
  - 떠 있는 도구 막대 `FloatingToolBar`와 사이드 패널 `ToolSidePanel`
  - 사진 평균색 글로우 `AmbientGlow`
  - 내 사진으로 그린 배치 썸네일 `LiveTemplateThumbnail`

  - 인화 연출 `ExportDialogs.Reveal`
- 햅틱: 배치·스타일·크기를 고를 때 `SegmentTick`, 섞기·자리 바꾸기·저장 완료 때 `Confirm`

## 6. 두 번째 테마 — "가족 앨범" 젤리 (v1.3 → v1.5에서 전면 개편)

홈 화면 오른쪽 위의 알약형 스위치로 **다크룸 ↔ 가족 앨범**을 고른다. 고른 값은 기기에 저장된다(`settings` SharedPreferences, 기본값은 다크룸).
v1.3의 크림·테라코타 버전은 색만 바꾼 수준이었다. v1.5에서는 **질감, 모양, 서체, 모션**까지 바꿔 "말랑말랑한 젤리"로 다시 만들었다.

### 리서치 (2026-09-24)
| 출처 | 가져온 것 |
|---|---|
| 가족 사진 앱(FamilyAlbum, Tinybeans 등)과 색채 심리 | 가족·아이 앱은 **따뜻하고 부드럽고 안전한 느낌**을 추구한다. 파스텔은 친근함과 신뢰를 준다. 버터 옐로는 부드러운 낙관, 피치·코랄은 따뜻함을 준다 |
| 2026 UI 트렌드 "Digital Texture" / Jelly UI | 버튼이 젤리·점토처럼 보이고, 누르면 **찌그러졌다가 튕겨 돌아온다** |
| 클레이모피즘 레시피(Setproduct 외) | 외곽 그림자는 **표면 색을 어둡게 한 색**으로 넣는다(회색 금지). 위쪽에는 흰 하이라이트, 아래쪽에는 짙은 음영을 넣는다. 모서리는 카드 24~32dp. **둥근 서체만** 쓴다. 누르면 그림자가 줄며 가라앉는다 |
| 애니메이션 원칙(squash & stretch) | 누를 때는 부피를 유지한 채 넓고 납작해진다. 놓을 때는 감쇠가 약한 스프링으로 출렁이며 돌아온다 |

### 색 — "딸기우유 위의 젤리"
| 역할 | 색 | 쓰임 |
|---|---|---|
| 바탕 | 딸기우유 `#FFF4EA` + 떠다니는 캔디 방울(꿀·딸기우유·민트·하늘·복숭아) | 모든 화면 뒤 |
| 채움 강조 | **꿀 젤리 `#FFC94D`** + 코코아 글자 `#4A3228`(8.5:1) | 선택된 칩·탭, 섞기 주사위, 업데이트·배경화면 버튼 |
| 주요 버튼 | **딸기 젤리 `#C73A4A`** + 흰 글자(4.5:1 이상) | 저장, 공유하기, 알겠어요 |
| 글자 강조 | 딸기 `#C73A4A` (`AccentInk`) | 헤드라인 강조, 선택 테두리, 아이콘 |
| 보조 | 민트 `#7FD1AE`, 딸기우유 핑크 `#FF8FA3` | 브랜드 마크 |
| 글자 | 코코아 `#4A3228` / 라테 `#735649` | |
| 폰 그림 | **딸기우유색 실리콘 젤리 케이스** `#FFB3C1`(화면은 실제처럼 어둡게) | 홈 히어로, 편집 화면 기기 테두리 |

다크룸은 채움 강조와 글자 강조가 같은 색(라임)이라 `Accent`와 `AccentInk`가 같다.

### 젤리 질감 (`ui/components/Jelly.kt`)
- `Modifier.jelly(color, shape)`는 네 겹으로 그린다
  1. 표면 색을 어둡게 한 색의 그림자
  2. 위는 밝고 아래는 짙은 몸통 그라데이션
  3. 위쪽 타원형 광택(젤리 곰 하이라이트)
  4. 밝은 윗테두리와 짙은 아랫테두리
- 음영 폭은 dp로 고정한다(최대 56dp). 작은 알약은 전체가 둥글게 보이고, 큰 패널은 가장자리만 둥글게 보인다
- `wfSurface`는 가족 앨범에서는 젤리로, 다크룸에서는 평평한 색으로 그린다. 다크룸 화면은 바뀌지 않는다
- `jellyButton` + `jellyButtonColors`: Material 버튼의 평평한 배경을 비우고 젤리 몸통을 보여 준다
- `jellyChip`: 선택되면 꿀 젤리, 아니면 평평한 색

### 모션
- **누르기**(`pressScale`, 앱 전체에 공통): 누를 때는 가로로 퍼지고 세로로 납작해진다. 단단한 스프링을 쓴다. 놓을 때는 감쇠 0.28의 출렁이는 스프링으로 돌아온다
- **선택**(`jellyPop`): 선택되는 순간 한 번 꿀렁 튄다(1.16 × 0.84에서 원래대로)
- **등장**(`jellyEnter`): 홈 카드가 순서대로 통통 떨어지며 자리 잡는다
- **배경**: 캔디 방울이 18초 주기로 천천히 떠다닌다. 그리기 단계에서만 갱신해서 다시 구성(recompose)하지 않는다
- 시스템 "애니메이션 삭제"를 켜면 위 모션이 모두 꺼진다(방울은 멈춘 채로 둔다)

### 서체
- 제목·버튼·칩: **Jua**(OFL, 예약 글꼴명 없음). 한글 2,350자와 영문만 남긴 서브셋이다(2.1MB → 1.3MB, `res/font/jua.ttf`, 라이선스는 `assets/licenses/Jua-OFL.txt`)
- 본문: Pretendard 500. 긴 글은 읽기 쉬워야 해서 바꾸지 않는다
- Jua는 굵기가 하나뿐이다. 그래서 가짜 볼드를 끈다(`FontSynthesis.None`). `·`, `×` 같은 기호는 시스템 글꼴로 대신 표시된다

### 테마 추가
- 테마를 추가하려면 `AppTheme`에 항목 하나와 `WfPalette` 하나를 추가한다
- 젤리 질감을 쓰려면 `jelly = true`와 `backdrop` 색을 준다
