## 2. 몰입을 만드는 설계 원칙 → 적용
| 원칙 | 적용 |
|---|---|
| 몰입(Flow): 목표가 분명하고 즉시 반응하며 방해가 없음 | 어두운 캔버스, 사진을 만지는 동안 도구 막대가 흐려짐, 편집 중에는 대화상자 없음 |
| 첫 즐거움까지의 시간 | 사진을 고르면 바로 완성된 콜라주가 나타나고, 칸이 스프링으로 "톡" 튀어나오며 채워짐 |
| 가변 보상 (Hook 모델) | **섞기(Shuffle)** 버튼: 같은 사진으로 새로운 배치·스타일·배경색을 무작위로 |
| 직접 조작 | 배치 썸네일에 **내 사진이 들어간 미리보기**를 보여 줌, 칸이 새 위치로 미끄러지듯 이동 |
| 마이크로 인터랙션·햅틱 | 배치 선택·섞기 때 가벼운 틱, 자리 바꾸기·저장 완료 때 확실한 클릭 |
| 피크엔드 법칙 | 저장을 클라이맥스로: "현상 중" 도형 모핑 → 흑백에서 컬러로 **인화되듯 나타나는 결과** → 크게 공유 |
| IKEA 효과 | 섞기 뒤에도 손으로 다듬게 유도(선택된 칸 바로 조작) |
| 스큐어모피즘 | 다크룸·인화지 은유(현상 중, 인화 애니메이션), 기기 테두리 미리보기 |

피해야 할 것: 가짜 로딩 지연, 연속 사용 압박, 과도한 햅틱.
접근성: 텍스트 대비 4.5:1 이상, 터치 영역 48dp 이상, 시스템의 "애니메이션 삭제"를 켜면 모든 장식 모션을 끔.

## 4. 화면별 변경
- **홈**: 폴드 8이 접혔다 펴지며(커버 10:16 ↔ 메인 4:3) 안의 사진들이 다시 배치되는 히어로 애니메이션. 사진처럼 보이는 그라데이션을 써서 "그리드 고르기"로 오해하지 않게 함. 큰 헤드라인, 누르면 살짝 눌리는 목적 카드
- **에디터**
  - 투명한 상단 바와 라임 알약형 "저장" 버튼
  - 사진 평균색 앰비언트 글로우와 기기 테두리 안의 캔버스
  - 접었을 때: 화면 아래에 떠 있는 알약형 도구 막대(배치·사진·꾸미기·크기 + 섞기), 도구는 떠 있는 둥근 시트로 열림
  - 펼쳤을 때: 여백을 둔 떠 있는 둥근 사이드 패널
  - 배치 썸네일에 내 사진을 그려서 보여 줌
- **저장**: 도형 모핑 "현상 중…" 화면 → 인화되듯 나타나는 완성본(스프링 확대 + 햅틱) → 공유 / 배경화면 / 계속 편집
- **아이콘**: 검정 바탕에 라임 와이어프레임

## 6. 두 번째 테마 — "가족 앨범" 따뜻한 리퀴드 글래스 (v1.6)

홈 화면 오른쪽 위의 알약형 스위치로 **다크룸 ↔ 가족 앨범**을 고른다. 고른 값은 기기에 저장된다(`settings` SharedPreferences, 기본값은 다크룸).

### 변천
| 버전 | 방향 | 결과 |
|---|---|---|
| v1.3 | 크림 + 테라코타 | 색만 바꿔서 "과감하지 않다"는 피드백을 받았다 |
| v1.5 | 캔디 젤리(클레이모피즘, Jua 서체, 꿀렁이는 모션) | "너무 깬다"는 피드백을 받았다. 유치하고 과했다 |
| **v1.6** | **따뜻한 리퀴드 글래스** | 사용자가 세 후보(추억 매거진 / 스크랩북 / 리퀴드 글래스) 중에서 직접 골랐다 |

### 방향
- iOS 26 이후 가장 큰 흐름인 **반투명 유리 UI**를 따뜻하게 바꿨다
- 가족 느낌은 장식으로 내지 않는다. **가족 사진 자체의 색**으로 낸다
  - 에디터의 배경은 사용자가 고른 사진을 크게 흐린 것이다
  - 강조색도 그 사진들에서 뽑는다
- 출처: Liquid Glass(Apple WWDC 2025), Setproduct "Glassmorphism vs liquid glass (2026)", Orizon "Glassmorphism in 2026"

### 색
| 역할 | 값 |
|---|---|
| 배경(홈) | `#F8F5F3` 위에 복숭아 `#FFB08A`, 연보라 `#D9CCF5`, 하늘 `#A8D4F5`, 세이지 `#BFDDB0`, 로즈 `#F5B5BE` 빛이 천천히 떠다닌다. 노랑과 베이지 계열은 쓰지 않는다 |
| 배경(에디터) | 콜라주 사진 최대 4장을 90dp로 흐리고, 흰색을 30% 덮는다(베이지 막은 누렇게 보여서 뺐다) |
| 유리 | 흰색 50% 틴트, 28dp 뒤 흐림, 4% 노이즈, 위가 밝은 1.2dp 반사 테두리, 옅은 중립 그림자 |
| 강조(홈) | 코랄 `#C4513A`(흰 글자 4.6:1), 글자용 `#A8432F` |
| 강조(에디터) | 홈과 같은 코랄 하나. v1.6.0에서는 사진 색에서 강조색을 뽑았다. 그런데 세피아나 노란 톤 사진에서 겨자색이 나와 "누리끼리하다"는 피드백을 받고 v1.6.1에서 없앴다 |
| 글자 | `#2E2320` / `#66554C` |

### 구현 (`ui/components/Glass.kt`)
- 뒤를 흐리는 블러에는 **Haze 2.0.0**(Apache-2.0)을 쓴다
  - 각 화면이 `GlassBackdrop`에 `hazeSource`를 달고, `LocalGlassState`로 상태를 내려준다
  - 유리 표면은 `hazeBlur(HazeInput.Sources(state), …)`로 그린다
  - 에디터에서는 콜라주 캔버스도 소스(zIndex 1)다. 그래서 캔버스 위에 뜬 막대는 사진을 흐리게 비춘다
- Android 12 미만이거나 블러 소스가 없는 창(대화상자)에서는 틴트를 90% 이상으로 올려 읽기 쉽게 한다
- `wfSurface`는 다크룸에서는 평평한 색이다. 다크룸 화면은 바뀌지 않는다. 강조색 표면은 흰 글자를 올리므로 거의 불투명(92%)하게 그린다
- `glassButton` + `glassButtonColors`: Material 버튼의 배경을 비우고 유리를 보여 준다
- `glassChip`: 선택되면 강조색 유리
- 모션: 누를 때는 다크룸과 같은 균일한 눌림을 쓴다. 홈 카드는 살짝 떠오르며 나타난다(`glassEnter`). 배경 빛은 24초 주기로 천천히 움직인다. 시스템 "애니메이션 삭제"를 켜면 모두 멈춘다
- 서체: Pretendard, 굵기 700/600, 자간은 다크룸의 절반만 좁힌다. Jua는 뺐다

## 7. 세 번째 테마 — "청사진" (v1.7)

레이아웃은 그대로 두고 **그리는 방식만** 바꾼 테마다. 업데이트 경로도 이 버전으로 함께 시험했다.

### 방향
- 시아노타입(청사진)은 1842년에 나온 **사진 인화법**이다. 동시에 앱 이름의 "와이어프레임"(설계 도면)이기도 하다
- 앱 전체를 **프러시안 블루 도면지 위의 기술 도면**처럼 그린다

| 요소 | 표현 |
|---|---|
| 바탕 | `#123F74` 그라데이션에 24dp 모눈을 긋고, 5칸마다 굵은 선을 넣는다. 가장자리는 살짝 어둡게 한다 |
| 표면 | 채우지 않고 1.5dp 흰 선으로만 그린다. 사진이나 다른 내용 위에 뜨는 큰 표면(시트, 대화상자, 막대)은 짙은 종이색(`#0E3563`)으로 채워서 글자 뒤로 사진이 비치지 않게 한다 |
| 재단 표시 | 떠 있는 표면의 네 모서리 바깥에 인쇄용 크롭 마크를 단다 |
| 선택 | 고른 것은 흰색으로 채우고 글자를 파랗게 한다. 고르지 않은 것은 **점선**(초안)으로 그린다 |
| 강조 글자 | 햇빛에 탄 주홍 `#FFB27A`(6.0:1) |
| 그림 | 홈의 폰과 목적 카드 미리보기 속 사진이 **선으로 그린 풍경**이 된다. 브랜드 마크도 선으로 그린다 |
| 서체 | Pretendard. 작은 라벨과 숫자는 고정폭 숫자(`tnum`)로 치수처럼 줄을 맞춘다. 모노스페이스 서체는 한글 간격이 벌어져서 쓰지 않는다 |
| 문구 | "어디에 쓸 콜라주, 도면부터 그려 볼까요?" / "청사진 뜨는 중…" |

### 글자 대비 점검 (v1.7에서 전 테마 공통으로 고침)
- 투명 표면에는 글자색을 따로 지정한다(`contentColor = Wf.Text`). 그래야 테마의 글자색이 적용된다
- 치수, 각주, 버전처럼 흐린 글자는 테두리 색(`outline`)이 아니라 보조 글자색(`onSurfaceVariant`)으로 쓴다
  - 다크룸에서는 이 글자들이 1.6:1로 거의 보이지 않았다. 지금은 모든 테마에서 4.5:1 이상이다
- 세 테마의 홈, 에디터, 꾸미기, 저장 대화상자, 완성 화면을 스크린샷으로 모두 확인했다

### 구현
- `WfPalette.style`(`Flat` / `Glass` / `Blueprint`)로 표면을 그리는 방식을 고른다
- `wfSurface`, `glassButton`, `glassChip`, `GlassBackdrop`이 스타일에 따라 유리 또는 청사진으로 그린다
- 청사진 전용 그리기는 `ui/components/Blueprint.kt`에 있다: `blueprint()`, `BlueprintPaper`, `drawWireScene`
