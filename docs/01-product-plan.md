# WireframePhoto — 기획서 (Galaxy Z Fold 8 전용 사진 콜라주 앱)

작성일: 2026-09-24 · 배포 형태: 서명된 APK 사이드로딩(Play 스토어 미등록)

## 1. 한 줄 정의

**접었을 때는 빠르게, 펼쳤을 때는 넓게** — 갤럭시 Z 폴드 8의 커버 화면(10:16)과 메인 화면(4:3)에 맞춰
UI가 바뀌는 사진 콜라주 앱. 폴드 화면 비율에 딱 맞는 배경화면·SNS용 콜라주를 고해상도로 저장한다.

## 2. 대상 기기 리서치 요약

| 항목 | Z Fold 8 | Z Fold 8 Ultra |
|---|---|---|
| 메인(내부) 화면 | 7.6", 2448×1848, **4:3 (가로가 기본 방향)** | 8.0", 2504×2256 (≈10:9) |
| 커버 화면 | 5.5", 1248×1972, **10:16 (세로)** | 6.5", 1080×2520, 21:9 |
| 폼팩터 | 펼치면 161.4×123.9mm, 가로로 넓은 "여권형" | 기존 Fold 7 계열 |
| OS | Android 17 / One UI 9 | 동일 |
| 칩셋·RAM | Snapdragon 8 Elite Gen 5, 12GB(1TB 모델 16GB) | 동일 |
| 카메라 | 50MP 메인 | 200MP 메인 → 원본 한 장이 12,000px를 넘을 수 있음 |
| S Pen | 미지원 | 미지원 |

설계에 반영한 점:

1. **펼친 화면은 가로가 기본이다.** 기존 폴드(세로로 긴 내부 화면)와 달리 폴드 8 내부 화면은 4:3 가로다.
   그래서 펼친 상태는 "왼쪽 캔버스 + 오른쪽 도구 패널" 2단 구성을 기본으로 한다.
2. **커버 화면은 10:16 세로이고 폭이 좁다(Compact).** 한 손으로 쓰는 빠른 흐름(사진 고르기 → 템플릿 → 저장)을
   1단 구성과 하단 시트로 처리한다.
3. **접기와 펴기 사이에 작업이 끊기면 안 된다.** 편집 중 화면이 바뀌어도 선택한 사진, 템플릿, 셀별 확대/이동
   상태를 그대로 유지한다.
4. **200MP 원본을 그대로 디코딩하면 메모리가 부족해진다.** 항상 필요한 해상도로 줄여서 디코딩한다.
5. **S Pen이 없다.** 모든 조작은 손가락 기준으로 설계한다. 터치 영역은 최소 48dp.

## 3. 경쟁 앱 분석과 차별점

(리서치 결과는 `03-research-notes.md` 참고)

- 대부분의 콜라주 앱은 1:1, 4:5, 9:16 같은 SNS 비율만 제공하고, **폴드 화면 비율에 맞는 배경화면 프리셋이 없다.**
- 광고, 워터마크, 구독 유도가 가장 흔한 불만이다. 이 앱은 **광고·워터마크·네트워크 권한이 모두 없다.**
- 폴더블 대응은 대부분 "화면이 늘어난 휴대폰 UI" 수준이다. 이 앱은 화면 크기(WindowSizeClass)와
  접힘 자세(테이블탑)에 따라 레이아웃을 바꾼다.

## 4. 핵심 기능 (MVP = v1.0)

### F1. 사진 선택
- 시스템 Photo Picker로 최대 9장을 선택한다. 저장소 권한이 필요 없다.
- 셀을 탭하면 그 셀에 들어갈 사진 한 장을 교체할 수 있다.
- (펼친 화면) 분할 화면에서 갤러리나 다른 앱의 사진을 셀로 **드래그 앤 드롭**해서 넣을 수 있다.

### F2. 레이아웃 템플릿
- 사진 1~9장용 템플릿 48종: 격자, 가로/세로 스트립, 1 큰 사진 + N 작은 사진, 모자이크.
- 선택한 사진 수에 맞는 템플릿을 먼저 보여준다. 기본 템플릿은 캔버스 비율에 맞춰 칸이 정사각형에 가깝고 크기가 고른 것을 자동으로 고른다.
- 템플릿은 정규화 좌표(0..1)의 사각형 목록으로 정의한다. 데이터만으로 템플릿을 추가할 수 있다.

### F3. 캔버스 비율 프리셋
| 그룹 | 프리셋 |
|---|---|
| 폴드 8 배경화면 | 메인 4:3(2448×1848), 커버 10:16(1248×1972) |
| 폴드 8 Ultra 배경화면 | 메인(2504×2256), 커버 21:9(1080×2520) |
| SNS | 1:1, 4:5, 9:16, 16:9, 3:4 |

### F4. 편집
- 셀 안에서 핀치로 확대하고, 드래그로 위치를 옮긴다(셀을 항상 채우는 center-crop 기준, 빈 공간이 생기지 않게 제한).
- 더블탭하면 확대/이동이 초기화된다.
- 길게 누른 뒤 다른 셀로 끌어다 놓으면 두 사진의 위치가 바뀐다.
- 간격(0~40), 바깥 여백(0~60), 모서리 둥글기(0~60), 배경색(프리셋 12색)을 조절한다. 단위는 캔버스 짧은 변의 1/1000이라서 저장 해상도가 바뀌어도 비율이 유지된다.
- 실행 취소/다시 실행 (최대 50단계).

### F5. 저장·공유
- JPEG(품질 95) 또는 PNG로 저장한다. 크기는 원본(프리셋 해상도, 폴드 프리셋은 실제 화면 해상도)과 절반 중에서 고른다.
- `Pictures/WireframePhoto` 폴더에 MediaStore로 저장한다(API 29 이상은 권한 불필요).
- 저장한 뒤 공유 시트를 연다.
- 폴드 배경화면 프리셋은 "배경화면으로 설정" 바로가기를 제공한다(시스템 배경화면 설정 화면으로 이동).

### F6. 폴더블 대응
| 상태 | 레이아웃 |
|---|---|
| 커버 화면 (Compact) | 캔버스를 위에, 도구 탭(템플릿·비율·스타일)을 아래 시트로 |
| 메인 화면 (Expanded, 가로) | 왼쪽 캔버스 + 오른쪽 도구 패널 (항상 펼쳐져 있음) |
| 메인 화면 (세로로 돌렸을 때) | 위 캔버스 + 아래 도구 패널 |
| 테이블탑 자세 (반쯤 접은 가로) | 접힌 선 위쪽에 캔버스 미리보기, 아래쪽에 도구 |
| 접기/펴기 전환 | 편집 상태를 100% 유지 (ViewModel + SavedState) |

## 5. 범위 밖 (v1.x 이후)
- 텍스트/스티커, 필터, 자유 배치(프리폼) 콜라주
- 프로젝트 저장 후 다시 열기(v1.1 후보)
- 클라우드, 로그인, 광고, 분석 SDK — 넣지 않는다

## 6. 화면 흐름 (v1.1 개편)

> v1.0 사용자 피드백: "들어가자마자 뭐가 뭔지 모르겠다" → **목적(용도)부터 묻고**, 도구를 4개로 묶고, 제스처를 직접 설명한다.

```
[홈] "무엇을 만들까요?"
  ├─ 갤럭시 Z 폴드 8 배경화면: 커버 화면 / 메인 화면   (기기 테두리 미리보기)
  └─ SNS·공유용: 인스타그램 피드 / 스토리·릴스 / 정사각형 / 가로 사진
        │ 카드 탭
        ▼
   Photo Picker (최대 9장) ──▶ [에디터] 캔버스 크기·기본 배치가 이미 맞춰진 상태
                                ├─ 처음 한 번 "이렇게 편집해요" 안내 카드 (? 버튼으로 다시 보기)
                                ├─ 배치 · 사진 · 꾸미기 · 크기  (4개 도구)
                                └─ 저장 ▶ [저장 완료: 공유 / 배경화면으로 설정 / 닫기]
```

### 화면 상태별 UI
| 상태 | 홈 | 에디터 |
|---|---|---|
| 접었을 때(커버) | 목적 카드 2열, 단계 안내 1줄 | 캔버스 크게 + **하단 도구 막대(배치·사진·꾸미기·크기)**. 누르면 도구가 막대 위로 열리고, 다시 누르거나 ⌄를 누르면 닫혀서 캔버스가 커짐 |
| 펼쳤을 때(메인) | 왼쪽 질문·3단계 안내, 오른쪽 카드 3열 | 왼쪽 캔버스 + 오른쪽 탭 패널(아이콘 위 글자) |
| 테이블탑 | — | 접힌 선 위 캔버스, 아래 탭 패널 |

### 알기 쉽게 만든 장치
- 배경화면용 캔버스는 **폰 테두리와 카메라 구멍** 안에 그려서 "내 화면"으로 보이게 한다.
- 빈 칸에는 "+ 사진 추가"라고 적는다. 누르면 바로 사진을 고른다.
- 칸을 선택하면 "N번 · 바꾸기 · 원래대로 · 빼기" 막대가 뜬다.
- 사진 도구에서는 사진 타일과 캔버스 칸에 같은 번호를 붙인다.
- 꾸미기 도구에 빠른 스타일(꽉 채우기, 얇은 테두리, 넓은 여백, 둥근 카드)을 둔다.
- 한국어는 단어 단위로 줄을 바꾼다("콜라 / 주"처럼 끊기지 않게).

## 7. 성공 기준 (로컬 검증 항목)
- 커버 화면 크기(1248×1972)와 메인 화면 크기(2448×1848) 에뮬레이션에서 UI가 잘리거나 겹치지 않는다.
- 편집 중 접기/펴기(화면 크기 변경)를 해도 상태가 유지된다.
- 9장(50MP급 포함)을 원본 크기로 저장해도 OOM 없이 3초 안에 끝난다(에뮬레이터 기준 참고치). → 달성: release 빌드에서 약 2~3초
- 저장된 이미지의 픽셀 크기가 프리셋과 정확히 일치한다.
- 서명된 release APK를 `adb install`로 설치해 실행할 수 있다.
